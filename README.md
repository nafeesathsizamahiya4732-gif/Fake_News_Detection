# Fake News Detection System

## About the Project

This project is used to detect whether a news article is real or fake.

The system uses Natural Language Processing (NLP) to process the news text and machine learning to classify it.

## Objective

The main aim of this project is to automatically detect fake news and help reduce the spread of misinformation.

## Dataset

The dataset contains news articles along with their labels.

The news is classified as:
- Real
- Fake

## Technologies Used

- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF

## Machine Learning Models

The following models were used:
- Logistic Regression
- Naive Bayes

## Steps

1. Loaded the news dataset
2. Checked the dataset
3. Handled missing values
4. Combined the news title and text
5. Cleaned the text
6. Removed stop words
7. Applied stemming
8. Converted text into numerical values using TF-IDF
9. Split the dataset into training and testing data
10. Trained the machine learning models
11. Compared the models
12. Predicted whether news is real or fake

## Result

The models were tested using accuracy, precision, recall and F1-score.

## Conclusion

This project shows how NLP and machine learning can be used to identify fake news automatically.
